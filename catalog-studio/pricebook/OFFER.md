# Proposed offer: one-time Pricebook Studio handover

Business proposal for review before use with a buyer. This file is not a signed customer agreement.

| Item | Proposed scope |
| --- | --- |
| Price | $12,500 once, before any applicable taxes |
| Buyer | One named business, internal use by its staff |
| License | Nonexclusive, perpetual use of the identified delivered version; seller retains the right to sell other licenses |
| Source | Supplied for that buyer's internal maintenance; no resale, sublicensing or white-label rights in the proposed license |
| Data | One approved import profile, one full snapshot of up to 1,000 SKUs per book |
| Pricing | USD, List plus up to four global percentage-discount tiers, one configurable gross-margin floor |
| Layout | The included catalog and price-sheet layouts, with company name, colors, contact, terms and supplied logo/photos |
| Delivery | Standalone HTML application, source/build instructions, sample outputs, private initial project, operating guide and acceptance record |
| Infrastructure | Runs locally; buyer owns its devices, file distribution and backups |
| Training | Self-service guide and in-product instructions; no scheduled staff training |
| Acceptance | Actual approved sample, agreed buyer computer/browser and expected outputs checked before final acceptance |
| Defect window | Proposed 30 calendar days from delivery to report reproducible deviations from agreed behavior; corrections included for those deviations |
| End of included work | Written acceptance and resolution of timely reported in-scope defects |
| Future changes | Not included: upgrades, additional formats/rules/layouts, new browser/OS support, integrations or ongoing operation |

Proposed payment stages: 50% after scope and sample fit are confirmed, 50% after acceptance and before unrestricted final handover. Agree those stages with the buyer in writing; no checkout or payment processing is built into the program.

The program blocks exports for detectable structural or pricing-rule errors. It cannot establish that a supplier's cost, product description, selling unit or image is factually correct. The buyer supplies and authorizes those facts and inspects each released edition.

The delivered copy continues to work without contacting the seller. There is no hosted activation, automatic update or remote kill switch. The proposed license defines the commercial rights; the program does not enforce a seat limit.

Customer projects, costs, photos and business information must be handled privately. The source repository contains fictional fixtures only. Source availability does not establish a right to sell or use a licensed production copy; agree the final license separately before a transaction.

Do not promise an exclusive code sale while planning to sell the same code repeatedly. Do not offer unlimited revisions, guaranteed revenue, zero defects, lifetime updates or ongoing operational responsibility under this price.
